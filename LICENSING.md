# Licensing and Citation

This file maps the licenses used by the framework. It is a scope record; the
license terms are in `LICENSE` and `LICENSE-docs`.

## Framework code — MIT

`LICENSE` applies to Dandelion Engineering-owned software and software-like
materials, including:

- Python programs and tests under `Tools/`;
- configuration and ignore files;
- code later added to playbooks or examples unless stated otherwise.

## Framework prose — CC BY 4.0

`LICENSE-docs` applies to Dandelion Engineering-owned prose and templates,
including:

- `AgentPrompt.md`, `README.md`, `SETUP.md`, and `DESIGN-RATIONALE.md`;
- `Project Details/`, `Research/`, `Outputs/`, and `Playbooks/` prose;
- instructional READMEs under `agents/`, `chats/`, `Work/`, and `Tools/`.

Suggested attribution:

> Collaboration Station Research 2.0 by Dandelion Engineering, licensed under
> CC BY 4.0. Changes, if any, noted.

## Projects created from the template

Copying the template does not license third-party research materials. Before a
project is released, update this file so it distinguishes:

- project-owned code and its chosen software license;
- project-owned prose, figures, and other authored materials;
- datasets, model weights, media, and other third-party assets, which remain
  under their source licenses;
- private or restricted materials that are not redistributed.

The project should document each dataset or material in
`Research/References.md` and in any distribution-specific data card or manifest
the Research Contract requires.

## Citation

`CITATION.cff` describes the framework as shipped. A public project created from
the template should replace that metadata with its own title, responsible human
authors or maintainers, version, release date, repository URL, and a transparent
description of material AI assistance consistent with applicable policies and
publication norms.
