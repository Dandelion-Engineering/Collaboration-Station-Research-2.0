# Research Outputs

Place durable project outputs here unless the Research Contract names a more
appropriate location.

The contract determines the output set from the claim and its readers. A
project may combine its final result, methods, exclusions, limitations, and
source record in one report, or separate them into a technical report, public
explanation, dataset card, software artifact, reproducibility packet,
simulation, dashboard, or other useful forms.

Do not create an artifact merely because an earlier project used it. Every
output should have a named reader, purpose, minimum content, and completion
evidence in `Research/Research Contract.md`.
