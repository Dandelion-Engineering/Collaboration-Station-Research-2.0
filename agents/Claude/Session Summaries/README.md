# Session Summaries

Create one numbered human-readable report for each completed session.

A useful report records:

- the real date and time;
- what changed and why;
- important evidence, decisions, and uncertainty;
- files created or updated;
- what is now usable;
- and the next valuable action.

The report is a durable handoff for the human director and future agents. It should not duplicate every command or become a second copy of the work.
